WordPress Image SEO: Size, Alt Text and Performance

Images can improve content and user experience, but oversized files can also increase page weight. WordPress sites benefit from an intentional image workflow.

Optimize before upload

Use appropriate dimensions and modern, efficient formats where supported. Avoid uploading a huge source image when the page only needs a small display size.

Write useful alt text

Alt text should describe meaningful image content when the image conveys information. Decorative images can use an empty alt attribute. Don't stuff keywords into alt text that does not describe the image.
